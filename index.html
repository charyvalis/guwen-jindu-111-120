第111課　兄弟爭田　《北史》

📜 原文

有百姓乙普明兄弟，爭田，積年不斷，各相援據，乃至百人。瓊召普明兄弟，對眾人諭之曰：「天下難得者兄弟，易求者田地。假令得地失兄弟，心如何？」因而下淚，諸證人莫不瀆泣。普明兄弟叩頭，乞外更思，分異十年，遂還同住。

📖 注釋

①積年：多年　②援據：引據、依據　③諭：開導　④如何：怎樣　⑤瀆泣：眼淚散落　⑥乞：希冀、盼望　⑦異：分開

🗣 語譯

北齊的時候，清河地方有個人叫乙普明，和他的弟弟為了爭奪田產打官司，幾年來不曾間斷，各自援引依據找人作證，竟然達到上百人。清河太守蘇瓊召喚乙普明兄弟過來，對大家開導說：「天底下最難能可貴的就是兄弟情誼，最容易得到的就是田地。假使爭得了田產，卻失去了兄弟情誼，又怎麼樣呢？」普明兄弟為此而掉下眼淚，各個證人也無不流下眼淚。普明兄弟叩頭，請求到外面去重新想一想。分開了十年的兄弟，於是又返家同住了。

📚 成語教室

【文學常識】《北史》：唐代李延壽撰，紀傳體史書，記述北魏、東魏、西魏、北齊、北周與隋的史事。　「假令得地失兄弟，心如何？」：假令＝假設語氣　天下難得者兄弟，易求者田地：蘇瓊以理勸說，感動兩兄弟　假令：假令＝假設語氣。　假設語氣用字：假、如、苟、若。　補充成語：狼狽為奸：比喻互相勾結，做壞事；沆瀣一氣（ㄏㄤˋ ㄒㄧㄝˋ ㄧˋ ㄑㄧˋ）：比喻氣味相投，後多用於貶義。

📝 隨堂練習

  1. 蘇瓊如何化解兄弟之間的紛爭？
    正確答案：(C) 曉之以理，動之以情
  2. 蘇瓊認為，天底下最難能可貴的是
    正確答案：(B) 手足之情
  3. 「諸證人莫不瀆泣」，是因為
    正確答案：(A) 感動
  4. 「分異十年，遂還同住。」表示兄弟之間
    正確答案：(C) 和好如初

第112課　身無長物　《世說新語》

📜 原文

王恭從會稽還，王大看之，見其坐六尺簟，因語恭：「卿東來，故應有此物，可以一領及我。」恭無言。大既去，即舉所坐者送之，既無餘席，便坐薦上。後大聞之，甚驚，曰：「吾本謂卿多，故求耳。」對曰：「丈人不悉恭，恭作人無長物。」

📖 注釋

①王大：王忱，是王恭的族叔長輩　②簟：竹蓆　③卿：你，稱呼晚輩或同輩　④一領：一張　⑤及我：贈我　⑥餘：多出的、剩下的　⑦薦：草墊　⑧丈人：對長上的尊稱　⑨悉：知道、了解　⑩長物：多餘的東西

🗣 語譯

王恭從會稽回來，王大去看望他，見王恭坐在六尺長的竹蓆上，於是對王恭說：「你從特產竹蓆的東方歸來，所以應該有很多竹蓆，可以拿一張送給我嗎？」王恭沒有答話。王大離去後，王恭立刻把自己坐的那張竹蓆送去。已經沒有多餘的蓆子了，王恭就坐在草墊上。後來王大聽說了這件事，非常驚訝，對王恭說：「我原先認為你有很多竹蓆，所以才向你索取的。」王恭回答說：「您不了解我，我這個人從來沒有多餘的東西。」

📚 成語教室

【文學常識】《世說新語》：南朝宋劉義慶編，筆記小說，記載漢末至東晉士人的言談、軼事，語言簡練傳神。　人稱代詞：汝＝爾＝子＝若＝君＝卿（你）；予＝余＝吾（我）；自謙：愚＝某＝僕　一介不取：一分一毫也不苟取，形容操守清廉＝一錢太守＝兩袖清風　補充成語：身無長（ㄓㄤˋ）物：長物指多餘的東西；身上沒有多餘的東西，比喻節儉或貧困；倚老賣老：自以為年紀大、閱歷豐富，而看不起別人。

📝 隨堂練習

  1. 根據本文，王恭的個性是
    正確答案：(A) 節儉清廉
  2. 下列關於本文的敘述，哪一個正確？
    正確答案：(C) 王恭家中只有一張竹簟
  3. 王大向王恭要竹蓆，是因為
    正確答案：(D) 認為王恭應該有很多張竹蓆
  4. 「身無長物」的意思是
    正確答案：(C) 身上沒有多餘的東西

第113課　歧路亡羊　《列子》

📜 原文

楊子之鄰人亡羊，既率其黨，又請楊子之豎追之。楊子曰：「嘻！亡一羊，何追者之眾？」鄰人曰：「多歧路。」既反，問：「獲羊乎？」曰：「亡之矣。」曰：「奚亡之？」曰：「歧路之中又有歧焉，吾不知所之，所以反也。」

📖 注釋

①楊子：楊朱，戰國時代思想家　②亡：失去　③率：帶領　④黨：鄉里親戚族之人　⑤豎：家中未成年的僮僕（小廝、奴才）　⑥嘻：表示驚訝語氣　⑦歧路：岔路　⑧反：同「返」　⑨奚：怎麼、為什麼　⑩之：往、到

🗣 語譯

楊朱的鄰居走失了一隻羊，帶領著鄉里親戚族人尋找，還請求楊朱家的小僮僕一起幫忙追趕。楊朱說：「奇怪！走失了一隻羊，為何要這麼多人去追呢？」鄰居說：「因為這一帶岔路太多。」大家回來後，楊朱問：「找到羊了嗎？」鄰居回答：「丟失了。」楊朱說：「怎麼會丟了呢？」鄰居回答：「岔路之中又有岔路，我們不知道往哪邊去追，所以就回來了。」

📚 成語教室

【文學常識】《列子》：傳為戰國列禦寇所作，道家典籍，書中多寓言故事，如愚公移山、歧路亡羊。　「之」字四義：1.助詞，的 2.助詞，無意義 3.動詞，到 4.代詞　豎：豎＝小廝＝僮僕（家中未成年的僕人）。　補充成語：歧路亡羊：比喻事理本同末異，繁雜多變，易使求道者誤入迷途，以致一事無成；掛羊頭賣狗肉：比喻表裡不一，企圖欺騙瞞混；羊毛出在羊身上：比喻所獲得的利益，實際上是來自本身；亡羊補牢，猶未晚也：比喻犯錯後及時更正，還能補救。

📝 隨堂練習

  1. 丟失羊的人是
    正確答案：(B) 楊朱的鄰居
  2. 羊找不回來的原因是
    正確答案：(C) 岔路太多，難以找尋
  3. 「奚亡之？」意思是
    正確答案：(B) 羊怎麼會丟失呢
  4. 根據這個故事，後人便用「歧路亡羊」來比喻
    正確答案：(D) 事理複雜多變，誤入歧途，而終無所成

第114課　正午牡丹　《夢溪筆談》

📜 原文

歐陽公嘗得一古畫牡丹叢，其下有一貓，未知其精粗。丞相正肅吳公與歐公姻家，一見，曰：「此正午牡丹也。何以明之？其花披哆而色燥，此日中時花也。猫眼黑睛如線，此正午猫眼也。有帶露花，則房斂而色澤。猫眼早暮則睛圓，日漸中狹長，正午則如一線耳。」此亦善求古人筆意也。

📖 注釋

①歐陽公：歐陽脩　②嘗：曾經　③精粗：精良和粗劣　④吳公：宋仁宗時丞相吳育　⑤披哆：綻放、綻開　⑥斂：收攏　⑦房：花冠　⑧鑒：鑑別

🗣 語譯

歐陽脩曾經得到一幅古畫，畫的是一叢牡丹，牡丹叢下有一隻貓，不知道畫的精良還是粗劣。丞相吳育與歐陽脩是親家，一看到就說：「這是正午的牡丹。怎麼知道呢？畫中的花瓣綻放而顏色乾燥，這是正午時的花。貓的瞳孔像一條線，這是正午時的貓眼。如果是早晨帶著露水的花，花冠是收攏的，顏色鮮潤。貓的眼睛在早晨和傍晚瞳孔是圓的，太陽漸漸移到正中，瞳孔就變得狹長，到正午時就像一條線了。」吳育說的話，也是善於觀賞、體會古人畫中的深意。

📚 成語教室

【文學常識】《夢溪筆談》：北宋沈括撰，筆記體著作，內容涵蓋天文、數學、地理、醫學、藝文等，保存豐富的科技與文化史料。　吳育「善求古人筆意」，建立在深切的觀察與體驗上：　判斷線索一：牡丹花：原文：其花披哆而色燥，此日中時花也；花瓣綻放（披哆）、顏色乾燥不潤澤，是正午時的花；對照：早晨帶露的花，花冠收攏（房斂）、顏色鮮潤（色澤）。　判斷線索二：貓眼：原文：猫眼黑睛如線，此正午猫眼也；貓的瞳孔在早晨、傍晚是圓的，太陽漸漸移到正中，瞳孔就變得狹長，正午時縮成一條線；畫中貓的瞳孔像一條線，所以判斷畫的是正午。

📝 隨堂練習

  1. 歐陽脩得到的古畫，畫的是
    正確答案：(D) 牡丹叢下有一隻貓
  2. 下列哪一個不是判斷畫中的時間是「正午」的原因？
    正確答案：(B) 牡丹花花冠是收攏的
  3. 吳育「善求古人筆意也」是建立在什麼基礎上？
    正確答案：(D) 生活中深切的觀察與體驗
  4. 由吳育的話中可以看出，下列哪一句適合用來形容這幅牡丹圖？
    正確答案：(A) 精確寫實

第115課　不忍之心　《韓非子》

📜 原文

孟孫獵得麑，使秦西巴持歸烹之。麑母隨之而啼，秦西巴弗忍而與之。孟孫歸，至而求麑，答曰：「余弗忍，而與其母。」孟孫大怒，逐之。居三月，復召以為子傅。其御曰：「曩將罪之，今召以為子傅，何也？」孟孫曰：「夫不忍麑，又且忍吾子乎？」

📖 注釋

①孟孫：春秋時魯國貴族　②麑：小鹿　③使：命令、派遣　④秦西巴：孟孫氏的家臣　⑤弗：不　⑥逐：驅趕　⑦居：停、過了　⑧召：呼喚，特別用於上對下　⑨傅：老師　⑩御：駕車的人　⑪囊：從前、往日

🗣 語譯

孟孫打獵得到一隻小鹿，命令臣子秦西巴把牠帶回去烹煮。小鹿的母親一路跟隨在後面啼叫，秦西巴心中不忍，就把小鹿還給了母鹿。孟孫回來後，向秦西巴要那隻小鹿，秦西巴回答說：「我不忍心，把小鹿還給了牠的母親。」孟孫非常生氣，把他趕走。過了三個月，孟孫又召秦西巴回來做自己兒子的老師。孟孫的車夫說：「以前您要處罰他，現在又召他來做兒子的老師，為什麼呢？」孟孫說：「他對一隻小鹿都不忍心傷害，又怎麼忍心對我的兒子不好呢？」

📚 成語教室

【文學常識】《韓非子》：戰國韓非著，法家集大成之作，善用寓言說理，如自相矛盾、守株待兔。　名言：惻隱之心，人皆有之。（《孟子》）人性本善，見人遭遇不幸而心生同情憐憫，是每個人都會有的　秦西巴因不忍母鹿哀鳴而放走小鹿，反而被孟孫認為有仁愛之心，任為其子之傅：

📝 隨堂練習

  1. 「秦西巴弗忍而與之」的「之」，指的是
    正確答案：(A) 母鹿
  2. 秦西巴為何放了小鹿？
    正確答案：(C) 憐憫小鹿，同情母鹿
  3. 「囊將罪之」的「罪」，詞性是
    正確答案：(B) 動詞
  4. 孟孫為什麼召秦西巴做自己兒子的老師？
    正確答案：(C) 秦西巴具有仁愛之心

第116課　水滴石穿　《鶴林玉露》

📜 原文

張乖崖為崇陽令，一吏自庫中出，視其鬢傍巾下有一錢，詰之，乃庫中錢也。乖崖命杖之，吏勃然曰：「一錢何足道，乃杖我耶？爾能杖我，不能斬我也。」乖崖援筆判曰：「一日一錢，千日千錢，繩鋸木斷，水滴石穿。」自仗劍下階斬其首。

📖 注釋

①令：縣令　②吏：職等較低的公務人員　③庫：貯藏物品的地方　④鬢：近耳旁兩頰上的頭髮　⑤幘：裹頭髮的布　⑥詰：盤問、責問　⑦勃然：發怒的樣子　⑧何足：哪裡值得　⑨仗：握著、持

🗣 語譯

張乖崖擔任崇陽縣令時，有一個小吏從府庫中走出來，張乖崖看見他的鬢髮旁、頭巾下藏著一文錢，責問他，原來是府庫中的公款。張乖崖下令杖打小吏，小吏發怒說：「一文錢哪裡值得一提，竟然杖打我？你能杖打我，總不能殺我吧！」張乖崖提筆寫下判決書：「一天偷一文錢，一千天就偷了一千文錢；像用繩子當鋸子，久了也能鋸斷木頭；小水滴不停的滴，也能滴穿石頭。」於是親自提劍走下臺階，斬了那個小吏。

📚 成語教室

【文學常識】《鶴林玉露》：南宋羅大經撰，筆記體著作，記載宋代人物軼事、詩文評論與議論。　「為」字四義：1.擔任，動詞 2.是 3.被 4.因為　繩鋸木斷，水滴石穿：只要持之以恆，微小的力量也能完成艱巨的事情　「爾」能杖我：此「爾」指張乖崖，不是小吏　補充成語：出言不遜：說話傲慢無禮；勿以惡小而為之：不要因為壞事很小就去做；星星之火，可以燎原：比喻小事能釀成大禍，或微小的力量可以發展成強大的勢力；前事不忘，後事之師：記取過去的經驗教訓，可作為今後行事的依據；人無遠慮，必有近憂：人如果不作長遠打算，預防可能發生的事態變化，很快的眼前就會有憂患的事情發生。

📝 隨堂練習

  1. 小吏偷錢被張乖崖發現後，反應是
    正確答案：(B) 惱羞成怒，出言不遜
  2. 小吏「一日偷一文錢」的行為，可以用哪一句話來勸諫？
    正確答案：(A) 勿以惡小而為之
  3. 下列「 」中哪一個不是代指偷錢的小吏？
    正確答案：(C) 「爾」能杖我，不能斬我也
  4. 「繩鋸木斷，水滴石穿」，意思是
    正確答案：(D) 只要持之以恆，微小的力量也能完成艱巨的事情

第117課　景差為相　《說苑》

📜 原文

景差相鄭，鄭人有冬涉水者，出而脛寒，後景差過之，下陪乘而載之，覆以上衽。晉叔向聞之曰：「景子為國相，豈不固哉！吾聞良吏居之，三月而溝渠修，十月而津梁成，六畜且不濡足，而況人乎？」

📖 注釋

①相：為相國，動詞　②涉：徒步渡水　③脛：小腿　④陪乘：隨從的車子　⑤衽：衣襟，指上衣　⑥圂：淺陋、鄙陋　⑦津：渡口　⑧梁：橋梁　⑨六畜：馬、牛、羊、雞、犬、豬　⑩濡：浸潤、沾濕

🗣 語譯

第118課　生木造屋　《呂氏春秋》

📜 原文

高陽應將為室家，匠對曰：「未可也。木尚生，加塗其上，必將撓。以生為室，今雖善，後將必敗。」高陽應曰：「緣子之言，則室不敗也。木益枯則勁，塗益乾則輕，以益勁任益輕，則不敗。」匠人無辭而對，受令而為之。室之始成也善，其後果敗。

📖 注釋

①高陽應：戰國時期宋國大夫　②室家：房屋、房舍　③匠：技術工人　④生木：剛砍下不久、水分未乾的木材　⑤塗：泥　⑥撓：彎曲　⑦敗：毀壞、損壞　⑧緣：依照、按照　⑨益：更加、越發　⑩勁：堅固有力　⑪任：擔負　⑫對：應答

🗣 語譯

高陽應準備興建一棟新房屋。工匠對他說：「還不行啊！剛伐下的木材水分未乾，如果抹上溼泥，會把木料壓彎的。用生木蓋房子，剛蓋成時雖然很好，以後一定會倒塌。」高陽應說：「按照您的話說，這房子一定不會損壞。因為時間一久，木料越乾燥就越堅固有力，而溼泥越乾就越輕。用越來越硬的木料去承受越來越輕的泥土，房子就不會倒壞。」工匠聽了無話可答，只得依照高陽應的意思去蓋。房子剛落成時雖然很好，後來果然倒塌了。

📚 成語教室

【文學常識】《呂氏春秋》：戰國末年秦相呂不韋集合門客編寫，屬雜家，兼採各家學說。　「為」：此處指建造　「益」字：增加、好處、有好處的、更加（見虛字整理）　強詞奪理：高陽應以「木益枯則勁」硬辯　一意孤行，不聽忠告，終致房屋倒塌：　補充成語：言不由衷：言詞與心意相違背；一針見血：比喻議論透澈而中肯。

  2. 高陽應回應工匠的話，可以說是

第120課　季札掛劍　《史記》

📜 原文

季札之初使，北過徐君。徐君好季札劍，口弗敢言。季札心知之，為使上國，未獻。還至徐，徐君已死，於是乃解其寶劍，繫之徐君塚樹而去。從者曰：「徐君已死，尚誰予乎？」季子曰：「不然。始吾心已許之，豈以死倍吾心哉！」

📖 注釋

①季札：春秋時代吳國公子，封於延陵　②使：出使　③過：拜訪　④好：喜愛　⑤弗：不　⑥上國：指齊、晉等中原之國　⑦塚：墳墓　⑧從者：隨待的人　⑨尚：還　⑩許：答應、應允　⑪倍：違背，通「背」

🗣 語譯

季札第一次出使，先去北方拜訪徐國的君主。徐君十分喜歡季札身上所佩的劍，口中卻不敢說。季札心裡也明白，但因為還要出使到中原各國，佩帶寶劍是一種禮節，所以沒有奉上。出使結束返回徐國時，徐君已經死了，於是解下寶劍，掛在徐君墳墓前的樹上，然後離去。隨從說：「徐君已經死了，你還要給誰呢？」季札說：「不是這樣的。當初我心裡已經答應要把劍送給他，怎麼能因為他死了就違背自己的心意呢！」

📚 成語教室

  2. 季札一開始未將寶劍送給徐君的原因是
    正確答案：(D) 將代表國家出訪別國，佩帶寶劍是一種禮節
  3. 季札後來仍將寶劍送給徐君的原因是
